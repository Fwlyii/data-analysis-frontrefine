# 可视交互系统

启动：`python3 app/launch.py --port 8766`，标准库即可，无模型请求。源码在src，匿名视图数据在data，图形与本地依赖在assets，runtime/dist由构建生成。

五章：简洁作答、中文数学、限长反弹、资料位置、反馈修复。主图使用Times New Roman可编辑SVG；可切换实验条件、查看数据与案例、下载SVG/CSV，位置支持九个实测条件，修复支持五个版本播放。

完整图表库保留柱/堆叠、时间线、路径、热力、散点、分组箱线、平行坐标和雷达等视图及匿名记录联动。ECharts、D3、Vega-Lite、Plotly依赖与许可证本地保存。

完整项目提供选定公开题库的实际回答案例；课程匿名提交版使用数值结果对照，原始全文不进入该目录。模型、任务和原评分分别解释，离线构建不执行生成代码。
