# 来源、匿名化与AI辅助

研究材料来自公开benchmark与自动模型实验，包含提示、模型回答、Token、请求状态、源评分和代码执行结果。具体来源及固定版本见各实验SOURCE/manifest和data/inventory中的校验信息。

原始数据在完整项目按原字节冻结。清洗统一字段与类型，原评分与环境排除分开；缺失值不填0，重复测量不当成独立问题。完整项目保留全文与源键映射；课程提交目录仅提供匿名数值特征、统计、图稿与代码，不包含模型对话全文或真实凭据。

生成式AI辅助了代码整理、清洗与统计实现、图形和文字表达。数据与结论来自保存的实验材料；未伪造人工审核标签。参与者同意等信息仅在实际涉及他人对话时按真实情况记录，不作代填。
