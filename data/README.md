# 数据层

- `raw/`：五个方向的完整原始材料，保留源文件字节；外层目录/文件名按实验内容统一。
- `processed/`：分实验规范表、题目/提示、修复事件和统一匿名索引。
- `quality/`：逐方向行数、唯一性、缺失值和评分适用范围。
- `inventory/`：原始字节与清洗表的SHA-256清单。
- `data_dictionary.md`：统一特征及分实验字段说明。

统一匿名索引248,586行：推理74,400、文档问答74,800、代码生成90,210、文档位置3,600、代码修复5,576。不同评分不合并成总体准确率。`record_lineage.csv.gz`保存本完整项目的源键映射，不进入课程匿名提交目录。
