# 代码生成实验

CodePromptEval的Python函数任务，221题经参考实现与题意审查保留194题，三模型、31条任务适配提示、五次独立生成，共90,210条回答。

使用保存的target-function-ast-v2测试结果。1题因统一环境问题排除，465条保留但不进入模型性能统计；193题、89,745条可评。环境排除不是模型失败。

Pass@k用五个已保存独立样本估计：1−C(5−c,k)/C(5,k)。观测累计成功按保存次序计算，二者分别标注。Prompt比较、错误率、输出开销与题目聚类区间见reports/code_generation。

提示不仅影响代码逻辑，也影响完整可执行函数的交付。提取失败、语法错误、运行错误和断言失败分别保留。五次独立生成不称为收到反馈后的多轮修复。

源采集、评分与分析实现位于experiments/code_generation/src；完整重新评分依赖原CodePromptEval的34个项目环境。日常离线分析只读保存结果，不执行模型代码。
