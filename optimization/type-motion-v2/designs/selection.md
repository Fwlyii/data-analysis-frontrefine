# 艺术字选择

本轮使用内置 image_gen 真正生成两份独立透明品牌素材，提示词、原始 PNG 和 SHA-256 见同目录 generation-manifest.json。参考为上一版真实桌面截图，没有用整页生图替换界面。

- A：海军蓝衬线 `LENS.`，E 中有青色光学切口，末尾青色点；在本页冷蓝、青色和透镜主题中识别度较好。
- B：另一版偏人文的字形，实际输出同样偏厚衬线，方向差异小于提示词意图；不把两图描述成已充分探索所有风格。
- 选择 A：四个字母和句点可读，轮廓简洁，缩到页眉实际尺寸后仍能识别；青色切口与透镜装饰有联系。以真实桌面和手机页面检查最终尺寸，而非仅看大图。

交付压缩为透明 WebP，600×200，13,086 bytes。可访问品牌名称仍由原生文本和链接 aria-label 提供；图片不可用时显示原生 `LENS.`。中文研究标题不是生图文字，而是原生可选中、可搜索的字体排版。

中文标题使用 Noto Serif CJK SC SemiBold 的 OFL 合法衍生子集，重命名为 LENS Editorial，统一 600 字重，调整字号、字距、行高；覆盖当前全部动态标题、证据区标题和基本 ASCII，共 174 个码点，交付 48,728 bytes。正文、操作控件和原始数据 SVG 保留原来的文字体系。本轮实际浏览器逐章核对字体为自定义字体，避免只检查 CSS 声明。
