# LENS 逐页交互实施计划

基线：main / 926c936a3571153eb855571b9ab7768e65c1c1f0。开始时工作区干净。本轮只开发和本地验证，不推送或发布。

## 设计判断

首页的价值是“操作引出内容，并在运动中保持方向感”。研究页借鉴这种关系，不复制球体外形。沿用深海蓝、雾蓝灰、冷白、少量香槟金；动效围绕真实点击发生，不自动改变研究条件，不加入新统计。研究阅读保持清楚，运动结束后图表回到原来的精确绘制状态。

参考 [Motion](https://github.com/motiondivision/motion) 的原生 JS 动画与可中断控制，复用项目已有本地 Motion mini 14.9.0；参考 [transition.css](https://github.com/argyleink/transition.css) 的揭示方向设计思路，不引入其样式包。[View Transition API](https://developer.mozilla.org/en-US/docs/Web/API/View_Transition_API) 作为跨状态过渡参考，本轮使用既有控制器与局部 Web Animations，避免浏览器截图过渡冻结图表操作。所有新视觉直接用 CSS/HTML 实现，无需额外位图。

每个含科学图的页面增加紧凑的操作导览和“聚焦图表”按钮。导览按视图分别写，点击展开；聚焦淡化周围阅读材料，突出原图面，Esc 或原按钮退出。不开新模态窗口，不搬动、克隆或缩放原图表，不截获原图交互。点击图表短暂出现外置光学反馈环，不写入科学 SVG。

## 实施与验收

1. 冻结当前构建为 `.git/interaction-review/baseline-dist`，建立 1,100 文件 SHA-256 清单。原全部 JS、CSS、科学数据和图稿保持字节一致。
2. 新增独立交互 JS/CSS；两个入口加载；构建负责复制和内容版本，不直接编辑 dist。
3. 源码推导完整 93 状态清单，包括 13 图形、4 代码视图、5 发现和全部既有条件组合。逐状态验证接入，不把公共外壳当成未审查页面的替代。
4. 新增真实操作测试：卡片/节点、导览、聚焦退出、条件切换、重复点击、开场、减少动态、驱动缺失、页面隐藏、键盘、详情、原导出。
5. 两个主要电脑尺寸逐页前后截图；五个电脑宽度完整巡检。额外窄屏检查新模块无横向溢出。
6. 对科学 SVG 结构、计算绘制样式和标准位置渲染像素进行逐页对照；真实 CSV/SVG 下载与冻结版本比较。
7. 查看实际截图检查不齐、裁切、序号与重复控件；发现失败保留记录，修复后重新执行对应检查。
8. 新版本发布门禁校验当次源指纹、完整路由、真实截图、保护清单和测试证据；历史 palette proof 封存，不沿用旧 PASS 冒充新验证。

普通点击 240ms，面板/图形揭示约480ms，分面错开最多160ms。支持减少动态、原生键盘与触摸，动画异常时保留可见内容。页面隐藏取消新动效，无新增持续循环；新监听器和观察器有释放入口。
