# 生图选择与实际还原

本轮通过内置 image_gen 实际生成三次，工具未返回具体模型版本。A/B 使用图表库真实桌面截图与首页品牌截图为参考；C 使用第一版实际手机截图与 A 为参考，重点调整手机布局。提示词与原图均保留。

| 维度 | A：独立筛选区与图纸 | B：一体式白色工作区 |
|---|---|---|
| 美观 | 轻、分组清楚，适合既有首页 | 完整，但整块白面板较重 |
| 层次 | 标题、筛选、图表三层明确 | 层次依赖内部细线 |
| 品牌一致 | 蓝青和白图纸延续首页 | 色彩一致，容器感更强 |
| 可读性 | 字段标签在选择框上方，扫描方便 | 同样可读，但控件分隔线较多 |
| 布局保留 | 保留原顶栏、筛选、整幅主图 | 同样保留，视觉上更集中 |
| 实现可行性 | 现有原生 DOM 与 CSS 可直接实现 | 需要重包多种动态视图的容器 |
| 响应式 | 筛选面板可自然切为两列 | 一体面板的手机内边距较难复用 |

选择 A。这是本次定性视觉判断，没有用户实验或独立评分服务。两图实际上都把桌面品牌与导航放进一行，未完全遵循提示词中的两行要求；生产代码采用与首页一致的两行公共外壳，保证手机五个主模式可见。

第一版真实手机截图显示标题与导出按钮分两行，筛选区间距较大，图表出现偏晚。再次调用模型得到 C（mobile-refinement.png），采用同一行标题/导出、全宽图形选择、其余四项两列分组和更紧凑的间距；第二版代码把图表上沿从约 535px 提前至约 459px，保留 40px 选择框和区域滚动提示。

不复制生成图的错误模型图标、渐变柱或重新绘制的数据；科学图与数据全部由原生渲染器和原 SVG 提供。此次三个生图输出都用于设计参考，不把整页图发给生产页面。已有品牌艺术字和透镜素材继续复用，本轮没有增加装饰下载。
