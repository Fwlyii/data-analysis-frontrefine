## 同一场景如何连续交接

| 时段 | 行为 |
| --- | --- |
| 0–3.12s | 原粒子、数据流与光学透镜镜头 |
| 3.12–4.08s | 五个真实链接以微光形态出现，从研究意象附近汇聚 |
| 4.08–5.06s | 品牌揭示，五个光点保持在中央光场附近 |
| 5.06–5.95s | 同一组链接放大为玻璃球，移向响应式目标坐标；标签依次揭示 |
| 片头结束 | 同一透镜 SVG 及96个刻度移交首页，同一组链接回到各自位置并恢复交互 |

五个球体不是结束后新建的替身：专项测试在开场中保存真实 DOM 引用，结束后逐一比较对象身份及所属容器。中央 `.intro-optics` 也比较了原始引用。两者在四种设备宽度下均保持同一节点。

直接跳过片头时显示独立的静态 SVG 回退；真实片头运行并交接后，回退图隐藏，只显示共享透镜。重播时把同一透镜还给原 LensScene，未重复创建刻度。提前跳过会将光环补为完整状态；Canvas或模块失败仍能通过五个原生链接进入研究。

首次深链接在路由模块初始化之前就可能启动片头，因此共享场景同时检查当前状态与请求hash。新增专项验证确认 `?intro=1#position` 不会误借用门户球体，最终品牌仍落在原页眉、原图表仍可操作。

## 材质、运动与交互

- 玻璃球由透明径向渐变、SVG多层轮廓、高光弧、内侧反射和柔和光晕构成。中央镜片、前后轨迹、星点与悬浮目标形成空间层次；没有引入大型3D框架。
- 复用已存在的 Motion mini，为五个入口提供不同速度的微幅椭圆漂移。轨迹有界，文字保持朝向和可读；不会让入口快速换位。
- 鼠标或键盘聚焦暂停对应球体漂移，轻微放大并显示短介绍，其他入口降低亮度；点击等待有限聚焦动画完成，再调用原 `LENS_GO_TO`。
- 原生 `href`、修饰键和Enter语义保留。Tab、方向键、Home/End与清晰焦点可用；进入研究后焦点移交真实标题。
- 手机采用透镜置顶、双列触摸目标和第五个居中入口，支持必要的纵向滚动，未整体缩小桌面环绕图。球体触摸目标在受检尺寸中不小于120px。
- 背景为SVG星点与光学轨迹、CSS网格和柔和渐变。首页不另开逐帧JS绘制循环；可见首页的原生动画在离开首页、页面隐藏或减少动态效果时停止。原电影 RAF 与Canvas在片头结束后释放。

## 实际发现并修复的问题

1. 转场初版同时显示回退镜片和正在移动的真实透镜，造成重影：在交接期间隐藏回退图。
2. 手机减少动态效果样式曾覆盖球体居中定位，导致点击前位移：保留布局变换，只停止动画。
3. 短屏桌面顶端目标与中央镜片过近：针对短屏收紧尺寸和间距，五尺寸重新检查。
4. 自动化的“等待元素稳定后悬停”与持续浮动不相容：按真实操作先移动指针进入目标，再验证暂停、描述、高光与真实点击，不用强制点击跳过命中测试。
5. 提前跳过时，尚未画完的光学环需要补完；Canvas失败时也必须移除交接隐藏状态。
6. 初始浮动帧可能与交接落点差7px：让闭合漂移轨迹从零偏移开始，并实测交接后位置误差小于2px。
7. 片头前半段改变窗口大小时重新测量目标；点击飞行中变化则取消旧动作，避免延迟误跳转。
8. 首次研究深链接的片头比路由早初始化：以真实请求hash保护场景选择，保留内页原有转场。
