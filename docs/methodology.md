# 研究方法

## 任务与实验变量

推理/选择题比较四模型、三个benchmark及31种提示；文档问答比较模型、提示、资料数与证据位置；代码任务分别研究独立采样和收到执行反馈后的修复。原始文件冻结在data/raw，规范记录及统一匿名特征在data/processed。

文档提示实验的10篇资料位置为1/5/10，20篇为1/10/20；文档位置实验固定NoCoT、20篇资料，在1/3/5/8/10/13/15/18/20测量两模型。两组协议分开统计，模型的采集日期保留，不混接为一条曲线。

代码生成每题×提示独立采样五次，没有历史或反馈。代码修复每模型×题目共享初稿，四种处理各修改四轮；只有基础诊断结果可反馈，保留集结果不进入提示。

## 清洗与分类

字段使用snake_case；数值、布尔、JSON和UTC时间有明确类型。CSV空单元格为null，不填0。以实验条件和稳定源键识别记录，重复测量保留。环境排除、模型失败、截断、提取未决分别标记。

可见输出分类使用保存的规则：显式代码块、编号/步骤、列表、单行、其他多行；提示要求映射为14类。分类描述可见形式，不推断模型内部思考。规则和字段来源在scripts/cleaning/classify_and_audit.py与数据字典中给出。

## 评分与统计单位

推理沿用源评分及已保存覆盖，不统一改判为另一套语义标签。文档问答分别保留首行包含、最终答案严格匹配、最终答案包含、全文包含。代码生成读取target-function-ast-v2保存结果；465条环境排除的passed为null。修复指标为当前版本同时通过基础与保留集测试。

独立单位是题目，模型/提示/位置/轮次是重复条件。比较采用同题配对，区间按题目聚类重采样；主要bootstrap为5,000次，种子随对应统计清单记录。不同任务原评分不混合求总准确率。共享修复初稿只计一次物理调用，逻辑组视图不增加样本量。

## 解释范围

简洁表达对照以点估计和区间共同解释，未把“不显著下降”写成已证明等效。中文模板对照定位于MATH500，其分步表述也不同；输出语言不等同于内部思考语言。词数、字母数与Token是不同单位，提示软限制不是接口硬上限。代码测试通过仅说明通过当前测试。

数据与模型结果可按固定清单追溯；人工语义审核字段保留真实缺失，不计为已完成的审核。来源见sources.json，复算见reproducibility.md。
