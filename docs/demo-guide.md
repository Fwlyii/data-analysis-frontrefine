# 课堂展示顺序

1. **Research Question**：用输出表达、证据组织、执行反馈介绍研究问题。
2. **Collection Design**：三个任务方向共用31提示与同题对照，再介绍证据位置和反馈修复实验。
3. **Data Pipeline**：用真实匿名记录说明字段与空值，讲清环境排除、重复测量和共享初稿。
4. **Data Landscape**：切换推理、文档问答、代码与模型，比较31提示的Token–评分散点和热图。点选热图显示当前条件精确数值；刷新保留筛选。
5. **Core Findings**：简洁、中文数学为低维；模型×位置、反馈×轮次为多维；极紧限长为异常。九位置滑块与五版本播放带动图和数字变化，案例、数据表、方法按需展开。
