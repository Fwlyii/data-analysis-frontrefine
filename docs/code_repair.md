# 反馈驱动的代码修复

HumanEval+ Mini，164题、两个Qwen模型。每模型×题目共享初稿，四组各修改四轮：独立重采样、自行检查、仅通过/失败、具体失败输入与预期/实际结果。后三组保留历史，反馈仅来自基础诊断测试；保留集不反馈。

共5,576条物理回答，6,560条逻辑组视图复用初稿。主指标是当前版本完整测试通过率，不是历轮累计成功。

Qwen3第四轮具体反例141/164、自检129/164，配对差7.32 pp，区间[3.05,12.20]；Qwen2.5差1.83 pp。Qwen3初始诊断失败的30题中，自检修复3题、仅状态4题、具体反例15题。初始完整测试失败为38题，与诊断失败分母区分。

数据在data/raw/code_repair，清洗表与事件在data/processed/code_repair，结果在reports/code_repair/full。采集/预检/执行/分析源码位于experiments/code_repair/src。离线分析不重新执行生成代码；实际采集使用macOS沙箱。
