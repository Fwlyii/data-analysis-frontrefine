# 统计结果与图稿

| 目录 | 内容 |
|---|---|
| baseline | 推理与文档问答的分组、配对和原评分统计 |
| prompt_variants | 输出语言、词数/Token/字母/步骤、截断和提示差异 |
| code_generation | 独立采样、Pass@k、Prompt差异、错误分布 |
| code_diagnostics | 代码提取、重复与错误结构 |
| document_positions | 证据位置、同题状态和模型增益差 |
| code_repair/full | 反馈×轮次、配对区间与修复事件 |
| story | 主要发现findings.md、证据表、案例与科学主图 |
| figures | 出版SVG、PNG/PDF与源CSV |
| reproduced | 从统一匿名特征复算的条件汇总 |

现行文件校验见data/inventory/current_files.json，原始数据校验见raw_files.json。原始运行元信息保留其协议与来源，评分指标和统计单位分别解释。
